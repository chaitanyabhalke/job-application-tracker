# 🎯 AI Job Application Tracker

A full-stack web application to track job applications with AI-powered career tips.

## 🛠️ Tech Stack
- **Backend:** Java, Spring Boot
- **Database:** MySQL
- **Frontend:** HTML, CSS, JavaScript
- **AI:** Gemini AI API

## ✨ Features
- Add, view, and delete job applications
- Track status: Applied / Interview / Offer / Rejected
- AI tip button — gives personalized career advice for each application

## ⚙️ How to Run Locally
1. Clone the repo
2. Set up MySQL and update `application.properties` with your DB credentials
3. Add your Gemini API key in `application.properties`
4. Run `mvn spring-boot:run`
5. Open `http://localhost:8080`
